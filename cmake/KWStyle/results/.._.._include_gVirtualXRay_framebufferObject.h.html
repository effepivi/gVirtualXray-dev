56 /*!
57 FramebufferObject Class. This class encapsulates the FramebufferObject
58 (FBO) OpenGL spec. See the official spec at:
59 TAB http://oss.sgi.com/projects/ogl-sample/registry/EXT/framebuffer_object.txt
60
61 for details.
62
63 A framebuffer object (FBO) is conceptually a structure containing pointers
64 to GPU memory. The memory pointed to is either an OpenGL texture or an
65 OpenGL RenderBuffer. FBOs can be used to render to one or more textures,
66 share depth buffers between multiple sets of color buffers/textures and
67 are a complete replacement for pbuffers.
68
69 Performance Notes:
70 ESP   1) It is more efficient (but not required) to call Bind()*
71      on an FBO before making multiple method calls. For example:
72 TAB
73       FramebufferObject fbo;
74       fbo.Bind();
75       fbo.AttachTexture(GL_TEXTURE_2D, texId0, GL_COLOR_ATTACHMENT0_EXT);
76       fbo.AttachTexture(GL_TEXTURE_2D, texId1, GL_COLOR_ATTACHMENT1_EXT);
77       fbo.IsValid();
78
79     To provide a complete encapsulation, the following usage
80     pattern works correctly but is less efficient:
81
82       FramebufferObject fbo;
83       // NOTE : No Bind() call
84       fbo.AttachTexture(GL_TEXTURE_2D, texId0, GL_COLOR_ATTACHMENT0_EXT);
85       fbo.AttachTexture(GL_TEXTURE_2D, texId1, GL_COLOR_ATTACHMENT1_EXT);
86       fbo.IsValid();
87
88     The first usage pattern binds the FBO only once, whereas
89     the second usage binds/unbinds the FBO for each method call.
90
91   2) Use FramebufferObject::Disable() sparingly. We have intentionally
92      left out an "Unbind()" method because it is largely unnecessary
93      and encourages rendundant Bind/Unbind coding. Binding an FBO is
94      usually much faster than enabling/disabling a pbuffer, but is
95      still a costly operation. When switching between multiple FBOs
96 ESP      and a visible OpenGL framebuffer, the following usage pattern*
97      is recommended:
98
99       FramebufferObject fbo1, fbo2;
100       fbo1.Bind();
101         ... Render ...
102       // NOTE : No Unbind/Disable here...
103
104       fbo2.Bind();
105         ... Render ...
106
107       // Disable FBO rendering and return to visible window
108       // OpenGL framebuffer.
109       FramebufferObject::Disable();
110 */
