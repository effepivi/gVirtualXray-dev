gVirtualXRay: Installation guide

Get the software

The latest version is 1.1.0. Get the source code from a ZIP file or a tarball at http://gvirtualxray.sourceforge.net/downloads.php. Alternatively, get the latest version from our SVN repository using the following command:

svn checkout svn://svn.code.sf.net/p/gvirtualxray/code/tags/1.1.0 gvirtualxray-1.1.0

Requirements

To run a simulation, you will need a computer with a graphics processor unit (GPU). The library has been tested against GPUs made by Intel, Nvidia, and AMD. You can use Windows, Linux or Mac OS X.

To install the library from the source code, you will need CMake. It can be downloaded at https://cmake.org/. You will also need a modern C++ compiler supporting with C++11.

Required and optional dependencies

Many of the required (R) and optional (O) dependencies can be downloaded and built directly thanks to CMake. Note that it takes quite some time to build the project... but it makes your life easier.

Compilation

CMake creates Makefiles on Unix platforms (e.g. Linux and Mac OS X), Visual Studio Solution files on Windowsm, and XCode project files on Mac OS X. It sets your compiler, operating system, and other system variables.
