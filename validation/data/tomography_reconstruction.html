Tomography Reconstruction

The results presented here have been generated using validation_04.cxx. In this test, we will simulate the geometry as follows:

  • A cube, which has edge length of 3 cm, is made of soft tissue (HU ≈ 52).
  • Inside, a cylinder is inserted. It is made of bone (HU ≈ 1330), its height is 3 cm and its diameter is 2 cm.

The incident energy, Ii, is 80 keV (i.e. 0.08 MeV).

A set of projections is simulated using these properties. There are 360 different angles; and the angular step is 0.5 degrees. The angular span is 0 to 179.5 degrees (0.5 * (360 - 1) = 179.5). We consider the central slice only. A detector of 301 × 1 pixels is used. The pixel size is 0.300 × 0.300 mm2. The detector size is 9.030 × 0.030 cm2. For each pixel of the detector, for each angle, the energy Io transmited orthogonnaly throw the sample is recorded (see Fig. 2).

The Beer-Lambert law in the monochormatic case is defined as follows:

I o = I i × exp ( - ∑ ( μ × x ) )

It can be rewritten as follows:

I o = I i × exp ( - ∑ ( μ × x ) ) I o I i = exp ( - ∑ ( μ × x ) ) ln ( I o I i ) = ln ( exp ( - ∑ ( μ × x ) ) ) ln ( I o I i ) = - ∑ ( μ × x ) - ln ( I o I i ) = ∑ ( μ × x ) ln ( I i I o ) = ∑ ( μ × x )

The latter equality is equivalent to the Radon Transform:

R f ( L ) = ∫ L f ( x ) | ⅆ x | .

Ii is known, it is 0.08 MeV. Io is also known, it corresponds to the projections (see Fig. 2). ln(Ii/Io) can be computed, it is the sinogram (see Fig. 3).

Tomography reconstruction will inverse the Radon Transform using the sinogram. It produces a map of linear attenuation coefficients for the energy Ii. It can be performed using the filtered back projection (FBP) algorithm. We complete this task using GNU Octave (see script here). Fig. 4 shows the corresponding FBP reconstruction.

We extract a 10 × 10 region of interest (ROI) in each tissue (see Fig. 5). The average pixel value for each ROI provides an estimate of the corresponding linear attenuation coefficient. Tab. 2 summarises the results. The error is relatively low, it is below 4.0E-03 cm-1.
